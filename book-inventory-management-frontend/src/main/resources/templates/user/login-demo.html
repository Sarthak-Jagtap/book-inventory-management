Login API

POST /api/v1/auth/login
Home›User Module›Login
What this API does Authenticates the user with username and password. Returns a signed JWT token (HS256) containing userId, username, and roleName as claims. Token expiry is configurable. Include this token as: Authorization: Bearer <token> in all subsequent protected requests.
Response FieldTypeDescription
tokenStringJWT Bearer token
tokenTypeStringAlways "Bearer"
userIdIntegerLogged-in user's ID
userNameStringUsername
firstNameStringFirst name
lastNameStringLast name
roleNameStringAssigned role
