Validate Token

POST /api/v1/auth/validate-token
NEW
Home› User Module› Validate Token
What this API does Sends a JWT token to the backend and checks if it is still valid. Returns the token's embedded claims: username, user ID, and role name. Useful for checking token expiry without making a full protected API call.
