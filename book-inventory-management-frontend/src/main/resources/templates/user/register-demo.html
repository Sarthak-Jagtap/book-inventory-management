Register API

POST /api/v1/auth/register
Home›User Module›Register
What this API does Registers a new user. Validates: firstName (max 20), lastName (max 30), userName (unique, max 30), password (4-30 chars), phone format (XXX) XXX-XXXX. Returns the created user profile. Role defaults to RegisteredUser (role 2) unless specified.
FieldRequiredValidation Rules
firstNameYesMax 20 characters
lastNameYesMax 30 characters
userNameYesMust be unique, max 30 characters
passwordYesBetween 4 and 30 characters
phoneNumberNoFormat: (XXX) XXX-XXXX
roleNumberNoDefaults to 2 (RegisteredUser)
